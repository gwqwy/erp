设计文档见仓库上级目录 `../docs/`（01 计划书 / 02 架构 / 03 数据库 / 04 API 规范）。

- ✅ M0~M5：底座 + 进销存 + 财务一体化 + 生产制造 + CRM/HR/驾驶舱 + 审批/冲销/批次（详见 docs/ 与 git 历史）

  - **库存**：调拨（双仓过账、成本随迁）、盘点（账面快照→实盘→盈亏自动过账+凭证）、其他出入库（赠品/报废/领用）、**库存预警页**（安全上下限）

  - **system**：操作日志（AOP 自动记录全部写操作：人/接口/参数/耗时/成败）
  - **infra**：公告通知（发布/撤回）
  - 前端新增 10 页：库存调拨/盘点/预警/其他出入库、销售退货、采购退货、费用登记、应收账龄、公告通知、操作日志

## 快速启动

```bash
# 1. 依赖服务（MySQL 8 + Redis 7，需 Docker Desktop 已启动）
cd tiangong-erp && docker compose up -d

# 2. 后端（Flyway 首次启动自动建库建表 V1~V8，admin/admin123 自动创建）
mvn -DskipTests package
java -jar tiangong-server/target/tiangong-server-1.0.0-SNAPSHOT.jar

# 3. 前端 dev server（vite proxy 代理 /admin-api → 48080）
cd ../tiangong-ui && npm install
npm run dev
# 打开 http://localhost:5173 ，账号 admin / admin123
```

一键脚本（erp 根目录）：`启动数据库.bat` → `启动后端.bat` → `启动前端.bat`（`停止全部.bat` 收尾）。

闭环验证脚本：`node ../m1-smoke.mjs` / `m2` / `m3` / `m4` / `m5-smoke.mjs`（M5 覆盖审批流、FIFO 拆分、红字冲销、报表、请假、动态表单、质检 13 步）。

## 开发约定（红线）

1. 跨模块只走 `api` 包接口，禁止直连他模块 Mapper；
2. 写库存只准经 `StockPostingService`（M1 落地）；单据状态流转走统一状态机；
3. 金额一律 `BigDecimal`；新表先过《03-数据库设计》规范再建；
4. 新增页面优先用 CrudPage/TreeCrudPage 配置，复杂单据才手写页面。
