# 天工 ERP（TianGong ERP）

> 企业自用全模块 ERP · Spring Boot 3 + Vue 3 · 模块化单体
> 设计融合：**Odoo**（模块化/元数据/Chatter/库存双账）+ **ruoyi-vue-pro**（工程底座）+ **yudao-ui-admin-vue3**（前端基座）+ **Metasfresh**（制造/MRP/业务财务一体化）
